Панель управления поддерживает запуск и базовое управление любыми игровыми серверами и приложениями. 
В этом мануале пойдёт речь о создании новой игры на примере Sven Co-op. К каждому шагу будут пояснения.

Если для игры есть Pelican или Pterodactyl egg, его можно импортировать, а не заполнять всё вручную —
см. [Импорт игр](/ru/gameap_configure/games_import.html#импорт-из-других-панелей).

## Создание игры

Сперва необходимо перейти на страницу добавления игры. Перейдите в меню **"Администрирование"** затем выберите 
**"Игры"**.

![Пункт «Игры» в разделе «Администрирование» бокового меню](/images/ru/tutorials/additional_games/game_menu.png)

После этого на странице вверху найдите кнопку **"Добавить игру"** и нажмите на неё.

![Кнопка «Добавить игру» вверху страницы со списком игр](/images/ru/tutorials/additional_games/add_game_menu.png)

Вы перейдёте на страницу с добавлением новой игры. Здесь вам нужно указать некоторые данные вашей новой игры.

![Окно добавления игры, заполненное на примере Sven Co-op](/images/ru/tutorials/additional_games/example_add_svencoop.png)

Вам нужно обязательно указать следующие поля:
* **Код**. Укажите сокращённое название игры
* **Старт код**. Можете также указать сокращённое название игры.
* **Имя игры**
* **Движок игры**. Если игра написана на Unity или написана без использования движка, то укажите сокращённое
название игры
* **Версия**. Укажите номер версии либо смысловое значение, например “legacy”, “beta” и т.п.

Важно! Для возможности автоматической установки необходимо обязательно указать одно из следующих полей: 
* [**Steam APP ID**](/ru/gameap_configure/games.html#steam-app-id). Значение для интересующей вас игры узнать на 
[официальной вики Steam](https://developer.valvesoftware.com/wiki/Dedicated_Servers_List), либо в базе данных 
[SteamDB](https://steamdb.info/)
* [**Удалённый репозиторий**](/ru/gameap_configure/games.html#удалённый-репозиторий). Ссылка на архив по HTTP или FTP
* [**Локальный репозиторий**](/ru/gameap_configure/games.html#локальный-репозиторий).

Все эти поля указывать не обязательно, но значение в каком-то одном из них обязательно должно быть.

Более подробно о значении полей читайте на странице [Настройка игр, описание полей](/ru/gameap_configure/games.html#описание-полей).

## Создание модификации

Для каждой игры должна существовать минимум одна модификация. 

Модификация — мощный инструмент в GameAP, вы можете включить дополнительные плагины, конфигурацию или любой контент для 
расширения базовых возможностей сервера. Архив с файлами, который вы укажете для модификации будет распакован поверх 
базовой сборки сервера.

Чтобы добавить новую модификацию для определённой игры, выберите в списке игру и нажмите **"Добавить первый мод"**.

![Кнопка «Добавить первый мод» в строке игры Sven Co-op](/images/ru/tutorials/additional_games/example_menu_add_mod_svencoop.png)

Если для игры уже есть хоть одна модификация, то на самом верху страницу со списком игры выберите 
**"Добавить модификацию"**.

На странице создания модификации укажите имя модификации, его можете придумать сами в зависимостей от особенностей
режима игры (GunGame, Jail и т.п.), либо наличия каких-либо модулей (AMXX, ReAMXX для Counter-Strike,
 IndustrialCraft, BuildCraft для Minecraft и т.п.).
 
![Окно добавления модификации с выбранной игрой Sven Co-op](/images/ru/tutorials/additional_games/example_add_svencoop_mod.png)

Если у вас есть архив с дополнительными плагинами, которые необходимо записать поверх базовой сборки, то укажите путь к
нему в полях локальный или удалённый репозиторий. 

В поле **локальный репозиторий** нужно указывать путь к архиву либо каталогу на выделенном сервере, 
на котором запущен GameAP Daemon, пример пути `/srv/gameap/repo/svencoop_op4_maps.tar.xz`. 
Подробнее на странице [Настройка игр](/ru/gameap_configure/games.html#локальный-репозиторий-1).

В поле **удалённый репозиторий** нужно указывать url к архиву на HTTP или FTP. 
Пример пути `https://cdn.gameap.ru/svencoop/svencoop_op4_maps.tar.xz`.
Подробнее на странице [Настройка игр](/ru/gameap_configure/games.html#удалённый-репозиторий-1). 
Готовые архивы для многих игр есть в хранилище GameAP (`cdn.gameap.ru`, `cdn.gameap.com`), но
посмотреть их список нельзя — каталог закрыт, работают только прямые ссылки. Обычно проще взять
готовые настройки игры кнопкой **«Обновить игры»**: в них адреса уже указаны.

## Конфигурирование модификации

После создания модификации откройте её для редактирования. В редакторе пять вкладок: **Основное**,
**Команды**, **Метаданные**, **Переменные** и **Fast RCON команды** — они описаны в разделе
[Редактирование модификаций](/ru/gameap_configure/games.html#редактирование-модификаций).

Начните с команд запуска по умолчанию во вкладке **Основное**. Полей два — **Команда запуска (Linux)**
и **Команда запуска (Windows)**, — и в каждый новый игровой сервер этой модификации копируется то,
что соответствует операционной системе выделенного сервера. Если оставить их пустыми, команда запуска
нового сервера тоже будет пустой, и сервер не запустится, пока вы не введёте её вручную.

![Вкладка «Основное» в настройках модификации с командами запуска для Linux и Windows](/images/ru/tutorials/additional_games/game_mods_edit_basic.png)

Примеры команд запуска по умолчанию для некоторых игр для Linux:
* Sven Co-op: 
```shell
./svends_run +ip {ip} +port {port} +maxplayers {maxplayers} +log on +map {default_map}
```
* Half-Life:
```shell
./hlds_run -game valve +ip {ip} +port {port} +map {default_map} +maxplayers {maxplayers} +sys_ticrate {fps}
```

* GTA: Multi Theft Auto
```shell
./mta-server64 -t -n --ip {ip} --port {port} --maxplayers {maxplayers}
```

Примеры команд запуска по умолчанию для некоторых игр для Windows:

* Sven Co-op:
```shell 
SvenDS +ip  {ip} +port {port} +maxplayers {maxplayers} +log on +map {default_map}
```

* 7 Day To Die
```shell
startdedicated.bat
```

Обратите внимание на значения в фигурных скобках `{` и `}`, такие как `{ip}`, `{port}`, `{maxplayers}`, `{default_map}`,
`{fps}` и другие. В GameAP это называется шорткодами, они заменяются на значения переменных сервера.
У всех игровых серверов есть базовые переменные, такие как IP, порты, ID, UUID. Дополнительные
переменные — максимальное количество игроков, карта по умолчанию, FPS и другие — объявляются в
настройках модификации, во вкладке **Переменные**.

![Вкладка «Переменные» в настройках модификации с развёрнутой переменной maxplayers](/images/ru/tutorials/additional_games/game_mods_edit_vars.png)

У каждой переменной есть тип — **Строка**, **Текст**, **Целое число**, **Дробное число**,
**Переключатель**, **Список** или **Пароль**, — а также могут быть заданы варианты значений, правила
проверки (обязательность, минимум и максимум, длина, регулярное выражение) и переводы подписи на языки
панели. Переменная с включённым флагом **Переменная администратора** обычным пользователям не
показывается вовсе; остальные появляются во вкладке **Настройки** каждого игрового сервера этой
модификации, где их значения меняются индивидуально. Поля описаны в разделе
[Переменные](/ru/gameap_configure/games.html#переменные).

Следующая вкладка, **Команды**, содержит RCON-команды для кика и бана игроков, смены карты и другие;
они используются для более расширенного управления игровым сервером.

![Вкладка «Команды» в настройках модификации с RCON-командами кика, бана и смены карты](/images/ru/tutorials/additional_games/game_mods_edit_commands.png)

Собственные RCON-команды задаются во вкладке **Fast RCON команды** — например команда статуса сервера
или получения статистики. Они показываются кнопками в RCON-консоли сервера.

![Вкладка «Fast RCON команды» с пользовательскими командами Status, Stats и Player list](/images/ru/tutorials/additional_games/game_mods_edit_fast_rcon.png)
