GameAP -- панель с открытым исходным кодом для управления игровыми серверами и сервисами.

## Функциональность

* Управление игровыми серверами и сервисами (запуск, остановка, перезапуск)
* Работа с файлами игровых серверов: редактирование, загрузка и скачивание, поиск по каталогу, контрольные суммы (MD5, SHA-1, SHA-256, SHA-512, CRC32, CRC64), создание и распаковка архивов прямо на выделенном сервере (zip, tar, gzip, bzip2, xz, zstd; 7z и rar — только распаковка)
* Управление игровыми серверами через RCON (отправка команд, просмотр консоли, управление игроками)
* Ограничение ресурсов игровых серверов (CPU, RAM)
* Типизированные настройки игровых серверов — строка, текст, целое число, дробное число, переключатель, список, пароль — с правилами валидации, заготовленными значениями и переменными только для администратора
* Планирование задач (автоматический перезапуск, обновление и т. д.)
* Контроль доступа (пользователи, роли, разрешения) и выдача пользователю доступа к конкретному серверу
* Единый вход (SSO): по запросу внешней системы, например биллинга, панель выпускает одноразовый билет, по которому конкретный пользователь входит в панель
* Произвольные метаданные выделенных серверов — пары «ключ — значение»; плагины помечают ими узлы, которые создают сами, например чтобы связать узел с облачным инстансом, на котором он работает
* Уведомления об обновлениях: на главной странице администратор видит установленную версию панели и последние выпуски GameAP и GameAP Daemon
* Интерфейс на четырёх языках — английском, русском, испанском и немецком (испанский и немецкий добавлены в 4.5)
* API для интеграции с другими системами и автоматизации. Документация по API доступна на [openapi.gameap.io](https://openapi.gameap.io/)

Функциональность панели расширяется плагинами. Плагины доступны в каталоге [plugins.gameap.ru](https://plugins.gameap.ru/).
Любой может разработать и опубликовать свой плагин (публикация проходит модерацию).
Плагины можно писать на любом языке, компилируемом в WASM: для Rust есть готовый SDK, есть примеры на Go и AssemblyScript.
Подробнее: [Плагины](/ru/plugins/index.html).

## Автоматическая установка панели

Доступно для Linux и Windows.

Нужно запустить скрипт, он автоматически установит необходимые пакеты и панель.
Установка займет всего несколько минут, а после её завершения вы сможете сразу же начать использовать панель.

* [Установка панели на Linux](/ru/install/install_on_linux.html)
* [Установка панели на Windows](/ru/install/install_on_windows.html)

Панель также распространяется готовым Docker-образом:

* [Установка панели в Docker](/ru/install/install_docker.html) — образ `gameap/gameap` вместо скрипта
