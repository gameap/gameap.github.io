## Добавление новых игр

Панель управления поддерживает запуск и базовое управление любыми игровыми серверами и приложениями. Если
в панели нет нужной вам игры, то вы можете её добавить.

Для добавления новой игры необходимо перейти на страницу **"Администрирование"** → **"Игры"**, затем выбрать 
**"Добавить игру"**.

После добавление игры добавьте первую модификацию этой игры и укажите параметры запуска игрового сервера.

### Описание полей 

#### Код

Код игры — это уникальное значение. Обычно это представляет собой сокращение от названия игры, например для игры 
"7 Day To Die" это `7d2d`. Код должен быть уникальным. Его можно придумать самому, главное, чтобы он был уникальным.

#### Старт код

Старт код обычно указывается в параметрах запуска. Это значение может быть любым, но чаще всего оно совпадает с кодом 
игры. Может совпадать с другими играми.

#### Имя игры

В имени игры нет ничего особенного — это полное название игры.

#### Движок игры

Движок игры — это система, на котором написана игра. Игры Half-Life, Counter-Strike написаны на движке GoldSource.

Half-Life 2, Counter-Strike Source написаны на Source. Иногда бывает, что неизвестно на каком движке написана игра,
в этом случае можно указать код игры или какое-либо сокращение от игры.

Для игр, написанных на GoldSource и Source следует указывать точно название движка. Для игр на Unity лучше указывать
какое-либо сокращение от игры, например Rust написана на Unity, но название движка указано как `rust`.
Игра Minecraft не написана с использованием какого-либо движка, поэтому название движка также указано как "Minecraft".

#### Версия движка

Числовая или строковое значение версии движка. Можно указать какое-либо смысловое значение, например "legacy", "beta"
и т.п.

#### Steam App ID

ID сервера игры в Steam. Используется для установки сервера через SteamCMD.
SteamID можно узнать на [официальной вики Steam](https://developer.valvesoftware.com/wiki/Dedicated_Servers_List), либо
в базе данных [SteamDB](https://steamdb.info/)

#### Steam App Set Config

Дополнительные параметры для установки сервера через SteamCMD. Некоторые значения можно узнать на можно узнать на 
[официальной вики Steam](https://developer.valvesoftware.com/wiki/Dedicated_Servers_List)

#### Локальный репозиторий

Путь на выделенном сервере к архиву либо к каталогу со сборкой игры, используемой как шаблон.
Этот путь должен обязательно присутствовать на выделенном сервере на который происходит установка нового игрового 
сервера. При создании нового игрового сервера архив будет распакован в рабочий каталог игрового сервера.

Поддерживаются следующие архивы: Zip, 7z, Tar, XZ, Bzip, GZip. 

RAR архивы не поддерживаются.

##### Примеры

В качестве примера рабочий каталог игрового сервера `/srv/gameap/servers/example-server`

| Значение поля "Локальный репозиторий" | Корректность значения | Результат при установке
| ------ | ------- | ------ |
| `/srv/gameap/repo/cs16_gungame.zip` | Корректно, при наличии архива на выделенном сервере | Содержимое архива `cs16_gungame.zip` будет распаковано в каталог `/srv/gameap/servers/example-server`
| `/srv/gameap/repo/cs16_public` | Корректно, при наличии каталога на выделенном сервере | Содержимое каталога будет скопировано в `/srv/gameap/servers/example-server`
| `/srv/gameap/repo/cs16_gungame.rar` | Некорректно. Архивы RAR не поддерживаются | Способ установки из локального репозитория будет пропущен либо сервер не будет установлен
| `https://cdn.gameap.ru/cstrike-1.6/rehlds-amxx-reunion.tar.xz` | Некорректно. Указано значение для удалённого репозитория | Способ установки из локального репозитория будет пропущен либо сервер не будет установлен


#### Удалённый репозиторий

Ссылка на удалённый источник. Это должен быть URL на HTTP или FTP ресурс. Архив должен быть доступен по прямой ссылке
без всяких промежуточных страниц, требующих ожидания или дополнительных действий. Ссылки к Yandex Disk, Google Drive и 
т.п. не поддерживаются.

Готовые сборки лежат в хранилище GameAP — `cdn.gameap.ru` для России и `cdn.gameap.com` для
остального мира. Просмотреть список файлов там нельзя: каталог закрыт, работают только прямые
ссылки. Проще всего не искать их вручную, а взять готовые настройки игр кнопкой
**«Обновить игры»** — в них уже прописаны нужные адреса,
см. [Импорт игр](/ru/gameap_configure/games_import.html#обновление-игр-из-каталога-gameap).

##### Примеры

В качестве примера рабочий каталог игрового сервера `/srv/gameap/servers/example-server`

| Значение поля "Удалённый репозиторий" | Корректность значения | Результат при установке
| ------ | ------- | ------ |
| `https://cdn.gameap.ru/cstrike-1.6/rehlds-amxx-reunion.tar.xz` | Корректно | Будет загружен архив `rehlds-amxx-reunion.tar.xz` и распакован в каталог `/srv/gameap/servers/example-server`
| `/srv/gameap/repo/cs16_gungame.zip` | Некорректно. Должен быть указан ресурс http или ftp | Способ установки будет пропущен либо игровой сервер не будет установлен.

## Добавление новых модификаций

У каждой игры может быть множество модификаций, каждая из которых обладает своими особенностями — настройками, 
параметрами запуска, конфигурационными файлами и т.п.

Для добавления новой игры необходимо перейти на страницу **"Администрирование"** → **"Игры"**, затем выбрать 
**"Добавить модификацию"**

### Описание полей

#### Игра

Игра к которой принадлежит модификация.

#### Имя

Имя модификации. Это может быть название аддона, сборки, ядра, какой-либо особенности и т.п. Укажите имя полностью на
своё усмотрение.

#### Репозитории

У модификации можеть быть свой собственный набор файлов и настроек, которые записываются поверх файлов основной сборки.
В архив с файлами вы можете включить какие-либо дополнительные плагины, дополнительные контент, звуки, музыку и т.д.
Поля локальный репозиторий не являются обязательными.

Поддерживаются следующие архивы: Zip, 7z, Tar, XZ, Bzip, GZip. 

RAR архивы не поддерживаются.

## Редактирование модификаций

После создания модификации откройте её для редактирования: **"Администрирование"** → **"Игры"**,
затем выберите модификацию в списке модов игры. Редактор разделён на вкладки:

| Вкладка               | Что на ней                                                                       |
|-----------------------|----------------------------------------------------------------------------------|
| **Основное**          | Имя модификации, локальные и удалённые репозитории, команды запуска по умолчанию |
| **Команды**           | RCON-команды: кик, бан, смена имени, перезапуск, смена карты, сообщение, пароль  |
| **Метаданные**        | Пары «ключ — значение», которые читает демон, например настройки контейнера      |
| **Переменные**        | Переменные, которые становятся настройками серверов и шорткодами `{...}`         |
| **Fast RCON команды** | Собственные RCON-команды, показываемые кнопками в RCON-консоли сервера           |

### Основные настройки

#### Имя модификации

#### Репозитории

Репозитории задаются отдельно для выделенных серверов на Linux и Windows: **Локальный репозиторий (Linux)**,
**Локальный репозиторий (Windows)**, **Удалённый репозиторий (Linux)**, **Удалённый репозиторий (Windows)**.
Подробнее в разделе [Добавление новых модификаций, репозитории](#репозитории).

#### Команды запуска по умолчанию

Полей два: **Команда запуска (Linux)** и **Команда запуска (Windows)**. Когда для модификации
создаётся игровой сервер с пустой командой запуска, в неё копируется поле, соответствующее
операционной системе выделенного сервера. Если пусто и оно, команду запуска придётся указывать для
каждого игрового сервера вручную — без неё сервер запустить невозможно.

В командах запуска можно использовать шорткоды — они заменяются на значения переменных сервера.
Шорткод — это слово без пробелов в фигурных скобках `{`, `}`, например `{ip}`, `{port}`, `{maxplayers}`.

##### Базовые шорткоды

Эти шорткоды доступны всегда, добавлять для них переменные в модификацию не нужно.

| Шорткод                             | Описание                                                             |
|-------------------------------------|----------------------------------------------------------------------|
| `{ip}`, `{host}`                    | IP игрового сервера                                                  |
| `{port}`, `{SERVER_PORT}`, `{PORT}` | Основной порт игрового сервера. Иногда называется connect-портом     |
| `{query_port}`                      | Порт для запросов (Query порт)                                       |
| `{rcon_port}`                       | Порт для коммуникации с сервером (RCON порт)                         |
| `{rcon_password}`                   | RCON пароль                                                          |
| `{id}`                              | ID сервера в панели                                                  |
| `{uuid}`                            | UUID сервера                                                         |
| `{uuid_short}`                      | Короткий UUID сервера                                                |
| `{dir}`                             | Абсолютный путь к рабочему каталогу сервера                          |
| `{game}`                            | Старт код игры                                                       |
| `{user}`                            | Системный пользователь, от имени которого запускается сервер         |
| `{node_work_path}`                  | Рабочий каталог демона на выделенном сервере, например `/srv/gameap` |
| `{node_tools_path}`                 | Каталог `tools` внутри рабочего каталога демона                      |

##### Определяемые пользователем шорткоды

Эти шорткоды вы определяете сами для каждой модификации во вкладке **Переменные**; они заменяются
на значения настроек игрового сервера. Подробнее в разделе [Переменные](#переменные).

При подстановке действуют два правила:

* Базовые шорткоды имеют приоритет: переменная с именем `port` или `dir` не изменит встроенное значение.
* Каждая переменная подставляется в трёх написаниях — как задана, полностью строчными и полностью
  ПРОПИСНЫМИ буквами. Переменная `maxplayers` заменит и `{MAXPLAYERS}`, а импортированная из
  Pelican egg переменная `SERVER_NAME` — и `{server_name}`. Другие варианты регистра не заменяются.

### Переменные

Переменные объявляются во вкладке **Переменные**. Каждая переменная становится настройкой каждого
игрового сервера этой модификации и шорткодом `{переменная}` для команды запуска. Значения
пользователи меняют на странице сервера во вкладке **Настройки** — см.
[Игровые серверы](/ru/gameap_configure/game_servers.html#настройки).

| Поле                          | Описание |
|-------------------------------|----------|
| **Переменная**                | Имя переменной без фигурных скобок: латинские буквы, цифры и подчёркивание, не начинается с цифры, не длиннее 32 символов. Каталог игр принимает только имена в нижнем регистре, и редактор предупреждает о других; сама панель принимает и прописные буквы, поэтому переменные, импортированные из Pelican egg, сохраняют свои имена |
| **Описание** (`info`)         | Короткая подпись рядом с настройкой, не длиннее 128 символов. Обязательное поле |
| **Тип**                       | Вид значения и виджет, который видит пользователь, см. [Типы](#типы). По умолчанию — **Строка** |
| **По умолчанию**              | Значение, пока у сервера нет собственного, не длиннее 64 символов. Для **Переключателя** должно совпадать с одним из его двух значений |
| **Описание** (`description`)  | Подробная подсказка под полем, не длиннее 1000 символов |
| **Переменная администратора** | Переменная видна только администраторам (пользователям с правом `admin roles & permissions`). Остальные не видят её во вкладке **Настройки** вовсе, а присланное ими значение игнорируется; администраторы видят её с пометкой **Только для администраторов** |

> В интерфейсе оба текстовых поля подписаны «Описание»: первое — однострочное (в API — `info`),
> второе — многострочное (`description`).

#### Типы

| Тип               | Значение `type` | Виджет и значение                                                                         |
|-------------------|-----------------|-------------------------------------------------------------------------------------------|
| **Строка**        | `string`        | Однострочное текстовое поле. Используется, если тип не задан                              |
| **Текст**         | `text`          | Многострочное текстовое поле                                                              |
| **Целое число**   | `int`           | Числовое поле для целых чисел                                                             |
| **Дробное число** | `float`         | Числовое поле, допускается дробная часть                                                  |
| **Переключатель** | `bool`          | Переключатель вкл/выкл; хранит **Значение при включении** или **Значение при выключении** |
| **Список**        | `select`        | Выпадающий список из заданных **Вариантов**                                               |
| **Пароль**        | `password`      | Текстовое поле со скрытым вводом                                                          |

![Раскрытый список «Тип» переменной на вкладке «Переменные» модификации: строка, текст, целое число, дробное число, переключатель, список, пароль](/images/ru/gameap_configure/games/var_type.png)

Каким бы ни был тип, значение хранится и подставляется в команды как строка.

**Переключатель.** По умолчанию два значения — `1` и `0`; их можно изменить (не длиннее 64 символов
каждое, они должны различаться). **Значение при выключении** может быть пустым — удобно для флагов,
которые либо есть в команде, либо нет. Значение по умолчанию должно совпадать с одним из двух.

**Список.** У каждого варианта есть **Значение** — строка, которая хранится и подставляется, не
длиннее 64 символов, уникальная в списке, — и необязательная **Подпись**, которую видит пользователь
(не длиннее 128 символов; если пуста, показывается значение). Нужен хотя бы один вариант. Если
включено **Разрешить произвольное значение**, пользователь может ввести значение, которого нет в
списке; оно проверяется правилами длины и шаблона, описанными ниже.

![Переменная типа «Список»: переключатель «Разрешить произвольное значение» и таблица вариантов со значениями и подписями](/images/ru/gameap_configure/games/var_options.png)

#### Проверка значения

Правила из блока **Проверка значения** проверяются при сохранении настройки сервера; значение,
нарушающее их, отклоняется. Правила действуют только для непустых значений — пустое значение
отклоняет только правило **Обязательное**.

| Правило                                       | Типы                                                   | Смысл |
|-----------------------------------------------|--------------------------------------------------------|-------|
| **Обязательное**                              | все                                                    | Пустое значение не принимается |
| **Минимум**, **Максимум**                     | Целое число, Дробное число                             | Границы значения; ими же ограничено числовое поле |
| **Минимальная длина**, **Максимальная длина** | Строка, Текст, Пароль, Список с произвольным значением | Длина значения в символах |
| **Шаблон (регулярное выражение)**             | Строка, Текст, Пароль, Список с произвольным значением | Значение целиком должно соответствовать выражению. Синтаксис RE2 — без опережающих проверок и обратных ссылок, не длиннее 512 символов. Поле **Проверочное значение** под шаблоном проверяет пример прямо в редакторе |

![Блок «Проверка значения» переменной: включённая обязательность, ограничения длины и шаблон, проверенный на примере](/images/ru/gameap_configure/games/var_validation.png)

Для **Списка** сам перечень вариантов — тоже правило: значение вне списка отклоняется, если не
разрешены произвольные значения. Текстовое значение без правила **Максимальная длина** всё равно
ограничено 4096 символами.

#### Переводы

Оба поля **Описание** и подписи вариантов вводятся на английском. Переводы для других языков панели
добавляются в блоке **Переводы** переменной (для обоих полей **Описание**), а для **Списка** —
кнопкой с иконкой языков рядом с каждым вариантом (для его **Подписи**). Выберите **Язык** — код
локали строчными буквами, например `ru`, `uk` или `pt-br`, — и введите переведённый текст. `en`
добавить нельзя: английский текст берётся из основных полей. Каждый язык можно использовать один
раз. Пользователь видит текст на текущем языке панели, а при отсутствии перевода — английский.

![Блок «Переводы» переменной с русским и немецким переводами обоих полей «Описание»](/images/ru/gameap_configure/games/var_translations.png)

### Метаданные

Вкладка **Метаданные** содержит произвольные пары **Ключ** / **Значение**, привязанные к
модификации. Из них демон берёт настройки контейнера, когда выделенный сервер запускает игровые
серверы в Docker или Podman: `docker_image`, `docker_workdir`, `docker_volumes`,
`docker_installation_script` и другие ключи `docker_*`. Ключ ищется по порядку: переменные сервера,
затем метаданные модификации, затем метаданные игры; значения должны быть строками. Кнопка **?**
рядом с полем **Ключ** открывает справочник **Ключи метаданных** со списком известных ключей и
примером для каждого; их описание — в разделе
[Менеджеры процессов](/ru/daemon/process_managers.html#docker).

### Команды RCON

Эти команды задаются во вкладке **Команды**. Они позволяют более расширенно управлять игровым сервером. Если игра поддерживает работу с RCON, либо 
поддерживается консоль, то можно делать следующее: кикать игроков с сервера, банить игроков, менять карту на сервере,
отправлять текстовые в общий чат, устанавливать пароль.

Некоторый функционал может быть ограничен самой игрой или модификацией. Например, не все игровые серверы поддерживают
вход на сервер по паролю.

#### Команда кика

Позволяет установить команду RCON, которая будет использоваться для выкидывания игрока с сервера.

Для команды можно задать шорткоды, которые будут заменены на данные определённого игрока

| Шорткод | Описание
| ------ | -------
| {id} | ID игрока на сервере
| {name} | Имя игрока на сервере

Для многих игр на GoldSource/Source это команда: 
```text
kick #{id}
```

#### Команда бана

Позволяет установить команду, которая будет использоваться для временного или перманентного бана игрока на сервере.

Для команды можно задать шорткоды, которые будут заменены на данные определённого игрока

| Шорткод | Описание
| ------ | -------
| {id} | ID игрока на сервере
| {name} | Имя игрока на сервере
| {time} | Время бана
| {reason} | Причина бана

Для многих игр на GoldSource (Half-Life, Counter-Strike 1.6 и др.) под управлением AMX Mod X это команда: 
```text
amx_ban "{name}" {time} "{reason}"
```

#### Команда смены имени (ника)

Команда, которой будет меняться ник выбранного игрока.

Для команды можно задать шорткоды, которые будут заменены на данные определённого игрока

| Шорткод | Описание
| ------ | -------
| {id} | ID игрока на сервере
| {name} | Текущее имя игрока на сервере
| {new_name} | Новое имя игрока на сервере
| {reason} | Причина смены

Для многих игр на GoldSource (Half-Life, Counter-Strike 1.6 и др.) под управлением AMX Mod X это команда: 
```text
amx_nick #{id} {new_name}
```

#### Команда перезапуска

Позволяет установить команду мягкой перезагрузки сервера, без перезагрузки самого процесса игрового сервера. Обычно
этой командой перезапускается карта или раунд для какой-нибудь игры. Не поддерживается многими играми.

Для многих игр на GoldSource/Source это команда: 
```text
restart
```

#### Команда смены карты

Этой командой можно сменить карту на игровом сервере.

| Шорткод | Описание
| ------ | -------
| {map} | Имя карты

Для многих игр на GoldSource/Source это команда: 
```text
changelevel {map}
```

#### Команда отправки сообщения

Позволяет отправить сообщение в текстовый чат для всех игроков на сервере.

| Шорткод | Описание
| ------ | -------
| {msg} | Сообщение, которое будет отправлено на сервер

Для многих игр на GoldSource (Half-Life, Counter-Strike 1.6 и др.) под управлением AMX Mod X это команда: 
```text
amx_say "{msg}"
```

#### Команда установки/смены пароля

Позволяет установить пароль для игрового сервера, благодаря чему на сервер смогут зайти только игроки, которые знают
этот пароль.

| Шорткод | Описание
| ------ | -------
| {password} | Пароль, который будет установлен на сервере

Для многих игр на GoldSource/Source это команда: 
```text
password {password}
```

### Fast RCON команды

Во вкладке **Fast RCON команды** можно добавить собственные RCON-команды — например команду статуса
сервера, получение статистики или списка недавно отключившихся игроков. Они показываются кнопками в
RCON-консоли сервера; нажатие отправляет команду.

| Поле             | Описание                                                  |
|------------------|-----------------------------------------------------------|
| **Описание**     | Подпись кнопки в панели, не длиннее 128 символов          |
| **RCON команда** | Консольная команда, которая отправляется игровому серверу |

Подпись можно перевести: кнопка с иконкой языков рядом с записью открывает тот же блок **Переводы**,
что и у переменных, — `en` добавить нельзя, английский текст берётся из поля **Описание**.
