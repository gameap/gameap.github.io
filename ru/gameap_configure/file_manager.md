Файловый менеджер работает с файлами игрового сервера прямо из панели: просмотр и редактирование,
загрузка и скачивание, архивы, контрольные суммы, права доступа. Он находится на вкладке
**«Файлы»** на странице игрового сервера.

![Файловый менеджер на вкладке «Файлы» игрового сервера: панель инструментов над списком файлов](/images/ru/gameap_configure/file_manager/toolbar.png)

Все операции выполняются через GameAP Daemon на выделенном сервере и ограничены каталогом игрового
сервера — выйти за его пределы нельзя.

Для доступа пользователю нужно право `game-server-files` на этот сервер,
см. [Пользователи, роли и права](/ru/users.html).

## Загрузка файлов

Файловый менеджер всегда загружает файлы по частям через возобновляемую сессию, независимо от
размера файла. Файл делится на части по `FILES_UPLOAD_CHUNK_SIZE` (по умолчанию 8 МБ), части
отправляются параллельно, по четыре за раз, с тремя попытками на каждую.

Предельный размер файла — произведение размера части на `FILES_UPLOAD_MAX_CHUNKS`
(по умолчанию 100 000), то есть около 780 ГБ.

В API есть также эндпоинт загрузки одним запросом, `POST /api/file-manager/{server}/upload`,
с фиксированным пределом **100 МБ**. Интерфейс панели им не пользуется.

### Возобновление

Перед отправкой браузер считает контрольную сумму SHA-256 всего файла и передаёт её панели вместе
с параметрами загрузки. Панель отслеживает, какие части уже получены.

Если загрузка прервалась — закрылась вкладка, пропала сеть, — при повторной попытке панель сообщит
список недостающих частей, и будут отправлены только они. Заново отправлять весь файл не придётся.

Незавершённые загрузки живут `FILES_UPLOAD_SESSION_TTL` (по умолчанию 24 часа), после чего
удаляются фоновой уборкой с периодом `FILES_UPLOAD_JANITOR_INTERVAL` (по умолчанию 12 часов).

> Подсчёт контрольной суммы выполняется в браузере через WebAssembly. Если вы правили политику CSP
> и убрали `'wasm-unsafe-eval'` из `script-src`, загрузка файлов перестанет работать.
> См. [Безопасность](/ru/security.html).

### Загрузка каталогов

Кроме отдельных файлов можно загрузить каталог целиком — структура вложенных подкаталогов
сохраняется.

### Какие файлы разрешено загружать

Тип файла определяется **по его содержимому**, а не по расширению и не по тому, что сообщил
браузер. Разрешены по умолчанию:

* изображения: PNG, JPEG, GIF, WebP, BMP, ICO;
* текстовые файлы, включая конфигурационные — они определяются как `text/plain`;
* JSON, XML, CSV, YAML;
* PDF.

SVG и HTML по умолчанию не разрешены: в них можно спрятать скрипт.

Список разрешённых типов задаётся переменными, см. [Конфигурация](/ru/config.html):

| Переменная                    | Назначение                                                                            |
|-------------------------------|---------------------------------------------------------------------------------------|
| `FILES_UPLOAD_ALLOW_ARCHIVES` | Разрешить загрузку архивов: zip, tar, gzip, bzip2, 7z, xz                             |
| `FILES_UPLOAD_ALLOW_BINARY`   | Разрешить загрузку произвольных двоичных файлов (`application/octet-stream`)          |
| `FILES_UPLOAD_ALLOWED_MIMES`  | Дополнительные разрешённые типы; **дополняет** список по умолчанию, а не заменяет его |

## Скачивание

Отдельный файл скачивается как есть. Отдельный каталог панель упаковывает в **ZIP** и отдаёт одним
потоком, не создавая временный архив на диске; файлы укладываются без сжатия. Для нескольких
выбранных элементов скачивание не предлагается — чтобы забрать их разом, создайте архив командой
**«Архивировать»** и скачайте получившийся файл.

Общий размер и число файлов передаются в заголовках `X-Archive-Total-Bytes` и
`X-Archive-Total-Files` до начала тела ответа, поэтому панель показывает точный прогресс.
Символические ссылки сохраняются как ссылки; особые файлы (сокеты, FIFO, устройства)
пропускаются и перечисляются в записи `_SKIPPED.txt` в конце архива.

## Архивы

Архивы создаются и распаковываются на выделенном сервере: панель лишь запускает операцию
и показывает её ход.

### Создание

Выберите один или несколько файлов и каталогов и вызовите **«Архивировать»** из контекстного
меню. В диалоге **«Создать архив»** задаются имя и **«Формат»**: zip, tar, tar.gz, tar.bz2,
tar.xz или tar.zst. Формат определяется и по расширению в имени (распознаются также `.tgz`,
`.tbz2`, `.txz` и `.tzst`). Через API отдельный файл можно дополнительно сжать в одиночный gz,
bz2, xz или zst.

![Диалог «Создать архив» с именем архива и раскрытым списком форматов](/images/ru/gameap_configure/file_manager/archive_create.png)

Если файл с таким именем уже существует, диалог не даст продолжить, пока не отмечен флажок
**«Перезаписать существующий архив»**.

**«Дополнительные параметры»** открывают поле **«Уровень сжатия»**, 0–9. Пустое значение —
уровень по умолчанию для формата. `0` для zip и gzip означает укладку без сжатия; bzip2 и zstd
без сжатия работать не умеют, поэтому `0` для них — самый быстрый уровень; у xz уровней нет,
и значение игнорируется.

### Распаковка

Выберите один архив и вызовите **«Разархивировать»** из контекстного меню. Пункт появляется
для файлов с расширениями `.zip`, `.tar`, `.tar.gz`/`.tgz`, `.tar.bz2`/`.tbz2`, `.tar.xz`/`.txz`,
`.tar.zst`, `.gz`, `.bz2`, `.xz`, `.zst`, `.7z`, `.rar`. Форматы **7z** и **rar** поддерживаются
только на распаковку.

В диалоге **«Распаковать архив»** две настройки:

* **«Извлечь в:»** — **«В новую папку»** (по умолчанию; папка называется как архив без
  расширения) или **«В текущую папку»**.
* **«Если файлы уже существуют:»** — **«Пропустить существующие»** (по умолчанию),
  **«Перезаписать»** или **«Остановить с ошибкой»**. При выборе **«Перезаписать»** диалог
  предупреждает, что файлы с совпадающими именами будут перезаписаны.

![Диалог «Распаковать архив» с выбором папки назначения и поведения при конфликтах](/images/ru/gameap_configure/file_manager/archive_extract.png)

Права доступа, сохранённые в архиве, восстанавливаются. Архивы с паролем не поддерживаются:
операция завершается ошибкой `archive is encrypted, password required`.

### Ход операции и отмена

Каждая выполняемая операция показывается полосой прогресса с кнопкой **«Отменить»**; прогресс
передаётся по WebSocket. На создание и распаковку действуют ограничения по размеру и числу
файлов, см. [Ограничения](#ограничения).

![Идущая распаковка показана полосой прогресса с кнопкой «Отменить» под списком файлов](/images/ru/gameap_configure/file_manager/archive_extract_progress.png)

> Для операций с архивами требуется **GameAP Daemon 4.1.0 или новее**. При подключении демон
> объявляет возможность `archive`; если у демона узла её нет, панель отвечает
> `502 node does not support archive operations`. Контрольным суммам нужна та же версия демона,
> но отдельной возможности для них нет: со старым демоном запрос просто завершится ошибкой.

## Контрольные суммы

Щёлкните правой кнопкой по одному файлу и выберите **«Контрольные суммы»**. Диалог
**«Контрольные суммы файлов»** считает на выделенном сервере SHA-256, SHA-1, SHA-512, MD5,
CRC32 (IEEE) и CRC64 (ECMA-182).

Для файлов до 1 МБ SHA-256 и MD5 считаются сразу при открытии диалога, для более крупных — только
SHA-256. Остальные алгоритмы считаются по кнопке **«Вычислить»**. Щелчок по значению копирует его
в буфер обмена.

![Диалог «Контрольные суммы файлов» с посчитанными суммами выбранного файла](/images/ru/gameap_configure/file_manager/checksums.png)

Эндпоинт API принимает до 100 путей за один запрос и для каждого пути, который не удалось
обработать, возвращает отдельную ошибку.

## Поиск

Нажмите лупу на панели инструментов или **Ctrl+F** (**Cmd+F** на macOS). Поиск открывается и при
быстром наборе трёх символов вне текстового поля — набранные символы сразу попадают в строку
поиска.

Поиск не фильтрует список: он подсвечивает совпадающие имена и переходит между ними.
**Enter** или **↓** — следующее совпадение, **Shift+Enter** или **↑** — предыдущее,
**Esc** закрывает поиск.

![Строка поиска на панели инструментов и подсвеченные совпадения в списке файлов](/images/ru/gameap_configure/file_manager/search.png)

Ищутся только имена в текущем каталоге — сначала каталоги, затем файлы. Поиск не рекурсивный
и не заглядывает внутрь файлов. Регистр и диакритика не учитываются (`е` находит `ё`, `c` находит
`ć`), раскладка клавиатуры не важна: если набранный текст ничего не нашёл, он перечитывается так,
как если бы был набран в другой поддерживаемой раскладке — английской, русской, немецкой,
испанской.

## История

Кнопка **«История»** (значок часов) в строке пути показывает каталоги и файлы, с которыми вы
работаете чаще всего, на двух вкладках: **«История»** и **«Частота»**. На каждой вкладке —
до четырёх каталогов и четырёх файлов. Кнопка появляется, когда есть что показать.

* **«История»** — элементы за последние 30 дней, новые сверху.
* **«Частота»** — по рейтингу, который растёт на единицу при каждом посещении и уменьшается вдвое
  каждые 7 дней, поэтому старые «любимые» каталоги постепенно уступают место новым.

![Панель истории, открытая на вкладке «История», со списком недавних каталогов и файлов](/images/ru/gameap_configure/file_manager/history.png)

Каталог записывается примерно через 5 секунд пребывания в нём или сразу при открытии файла из
него — каталоги, через которые вы просто проходите, не записываются, корень не записывается
никогда. Удалённые элементы исчезают из истории, переименованные — переносятся. Щелчок по записи,
которой больше не существует, удаляет её.

История хранится **только в браузере**, в `localStorage` под ключом
`gameap:fm:history:{server}:{disk}`. Она не отправляется в панель и не разделяется между
пользователями, браузерами и устройствами. Для каждой пары «сервер — диск» запоминается
до 200 каталогов и 200 файлов.

## Ограничения

| Переменная                            | По умолчанию | Назначение                                                                                                                                                         |
|---------------------------------------|--------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `FILES_ARCHIVE_MAX_BYTES`             | `100G`       | Предельный размер несжатых данных одной операции: скачивания ZIP, создания и распаковки архива на выделенном сервере. При распаковке это защита от «архивных бомб» |
| `FILES_ARCHIVE_MAX_FILES`             | `500000`     | Предельное число записей в тех же трёх случаях                                                                                                                     |
| `FILES_ARCHIVE_CONCURRENT_PER_SERVER` | `2`          | Одновременных **скачиваний ZIP** на один игровой сервер; при превышении — HTTP 429. На создание и распаковку архивов не влияет                                     |

Если ограничение равно `0`, демон применяет собственные значения по умолчанию: 10 ГиБ
и 100 000 записей.

Ограничения загрузки описаны в разделе [Загрузка файлов](#загрузка-файлов); все переменные
перечислены в [Конфигурации](/ru/config.html).

## Права доступа к файлам

Для файла или каталога можно изменить права командой **chmod** — так же, как в оболочке.
Это нужно, например, чтобы сделать исполняемым скрипт запуска игрового сервера.

## Редактирование

Текстовые файлы открываются во встроенном редакторе. Плагины могут добавлять собственные
редакторы для определённых файлов — например шестнадцатеричный редактор для двоичных.
Файлы больше 1 МБ плагинными редакторами не открываются, кроме редакторов, которые загружают
файл самостоятельно (объявлены с `contentType: 'none'`) — они доступны при любом размере.
См. [Плагины](/ru/plugins/index.html).

## Аудит

Операции с архивами попадают в журнал аудита: `file.archive.create` (идентификатор операции,
формат, число источников), `file.archive.extract` (идентификатор операции, политика конфликтов)
и `file.archive.cancel` (идентификатор операции). Загрузки, отклонённые проверкой типа,
записываются как `file.upload` с именем файла, определённым типом и причиной `mime_not_allowed`.
Загрузки по частям и запросы контрольных сумм записей в аудите не создают.

## Если что-то не работает

| Признак                                                                                 | Причина                                                                                                                                 |
|-----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Загрузка завершается ошибкой **«Отклонено прокси (слишком большой запрос)»** — HTTP 413 | Обратный прокси отклонил часть файла. Увеличьте `client_max_body_size` в nginx так, чтобы он был больше `FILES_UPLOAD_CHUNK_SIZE`       |
| Загрузка завершается ошибкой **«Сессия истекла, повторите»** — HTTP 410 или 404         | Сессия загрузки истекла (`FILES_UPLOAD_SESSION_TTL`). Начните загрузку заново                                                           |
| Загрузка завершается ошибкой **«Несовпадение контрольной суммы»** — HTTP 422            | Файл изменился на диске во время загрузки. Начните загрузку заново                                                                      |
| Загрузка обрывается на подсчёте суммы                                                   | Из политики CSP убран `'wasm-unsafe-eval'`                                                                                              |
| Загрузка не начинается                                                                  | Нет права `game-server-files` либо демон недоступен                                                                                     |
| `node does not support archive operations` — HTTP 502                                   | GameAP Daemon на узле старше 4.1.0                                                                                                      |
| Скачивание ZIP завершается ошибкой HTTP 429                                             | Слишком много одновременных скачиваний для этого игрового сервера (`FILES_ARCHIVE_CONCURRENT_PER_SERVER`). Дождитесь окончания текущего |
| Распаковка завершается ошибкой `archive is encrypted, password required`                | Архив защищён паролем; такие архивы не поддерживаются                                                                                   |

Подробности видны в журнале панели, см. [Устранение ошибок](/ru/troubleshooting.html).
