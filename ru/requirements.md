GameAP 4 — один исполняемый файл со встроенным веб-интерфейсом. Веб-сервер, PHP, composer и Node.js
для работы панели не нужны.

## Системные требования

### Панель

* Оперативная память: 512 Мб и более
* Диск: 200 Мб и более
* К процессору панель не требовательна, одного ядра достаточно

### GameAP Daemon

Значения ниже — для самого демона, **без учёта игровых серверов**. Ресурсы под игровые серверы
считайте отдельно: у некоторых игр требования высокие.

* Оперативная память: 128 Мб
* Диск: 1 Гб и более, плюс место под файлы игровых серверов
* К процессору демон не требователен, одного ядра достаточно

Панель и демон можно установить на один сервер.

## Операционные системы

Сборки выпускаются для:

| Система | Архитектуры             |
|---------|-------------------------|
| Linux   | `amd64`, `arm64`, `386` |
| Windows | `amd64`, `arm64`, `386` |
| macOS   | `amd64`, `arm64`        |

Установка через `gameapctl` описана на страницах
[Установка на Linux](/ru/install/install_on_linux.html) и
[Установка на Windows](/ru/install/install_on_windows.html).

Поддерживаемые версии Windows перечислены на странице установки.

## Сеть

| Порт    | Кому нужен                                         | Обязателен                                 |
|---------|----------------------------------------------------|--------------------------------------------|
| `8025`  | Веб-интерфейс и API. Нужен браузеру администратора | да                                         |
| `31718` | gRPC. По нему демоны подключаются к панели         | да, если есть удалённые выделенные серверы |
| `443`   | HTTPS, если панель обслуживает его сама            | нет                                        |
| `80`    | Подтверждение Let's Encrypt по `http-01`           | да, если используется этот способ          |

Порты 8025 и 443 меняются переменными `HTTP_PORT` и `HTTPS_PORT`, порт gRPC — `GRPC_PORT`.
См. [Справочник config.env](/ru/config.html).

Демону нужен исходящий доступ к панели по порту 31718 — и это единственный порт панели, который
ему требуется. Панель к демону не подключается, входящие порты на выделенном сервере открывать
не нужно.

> Так работают версии **4.2 и новее**. В 4.0 и 4.1 обмен идёт по старому протоколу: подключается
> панель, а на выделенном сервере должен быть открыт **входящий порт 31717**. Это важно, если вы
> обновляетесь с GameAP 3 — такое обновление приводит именно на 4.1,
> см. [Обновление с v3 до v4](/ru/upgrade_from_v3_to_v4.html).

### Исходящие соединения панели

Сама панель выполняет несколько исходящих HTTPS-запросов. Ни один из них для работы панели не
обязателен: без исходящего доступа она лишь не сможет проверять обновления, обновлять каталог игр
и открывать каталог плагинов.

| Адрес                                               | Назначение                                     | Переменная                                                    |
|-----------------------------------------------------|------------------------------------------------|---------------------------------------------------------------|
| `cdn.gameap.com`, `cdn.gameap.ru`, `api.github.com` | Проверка новых выпусков GameAP и GameAP Daemon | `UPDATE_CHECK_URLS`; отключается `UPDATE_CHECK_ENABLED=false` |
| `cdn.gameap.ru`, `cdn.gameap.com`                   | Каталог игр                                    | `GAMES_CDN_URLS`                                              |
| `plugins.gameap.dev`                                | Каталог плагинов                               | `PLUGINS_STORE_URL`                                           |

## База данных

Нужна одна из:

| СУБД            | Примечание                                                          |
|-----------------|---------------------------------------------------------------------|
| PostgreSQL      | Рекомендуется для установок с несколькими экземплярами панели       |
| MySQL / MariaDB |                                                                     |
| SQLite          | Отдельный сервер базы данных не нужен, файл создаётся автоматически |

Для небольшой установки достаточно SQLite: он не требует ни отдельной службы, ни настройки.

Строка подключения задаётся переменными `DATABASE_DRIVER` и `DATABASE_URL`, форматы приведены
в [справочнике config.env](/ru/config.html).

Обновление с GameAP 3 без переноса данных возможно **только на версии 4.0 и 4.1** и только
с MySQL, MariaDB или SQLite. Для PostgreSQL такого пути нет, как и для версий начиная с 4.2.
Подробности и порядок действий — [Обновление с v3 до v4](/ru/upgrade_from_v3_to_v4.html).

## Необязательные компоненты

Нужны только в отдельных сценариях, для обычной установки — нет.

| Компонент       | Когда нужен                                                                  |
|-----------------|------------------------------------------------------------------------------|
| Redis           | Общий кэш и обмен событиями между несколькими экземплярами панели            |
| Хранилище S3    | Общее хранилище файлов и сертификатов ACME при нескольких экземплярах панели |
| Обратный прокси | Если HTTPS обслуживается nginx или Traefik, а не самой панелью               |

## Сборка из исходников (опционально)

Обычная установка использует готовые сборки, и ничего из перечисленного ей не нужно. Инструменты
сборки требуются только тогда, когда из исходников собирается панель или демон — флаг `--github`
у команд `gameapctl panel install` и `gameapctl daemon install`, а также у соответствующих
команд `upgrade`. См. [Установка на Linux](/ru/install/install_on_linux.html).

* GameAP 4.5.0: Go 1.27, Node.js с npm и git (релизы собираются с Node.js 24);
* GameAP Daemon 4.1.2: Go 1.26.5 и новее, а также git (Node.js не нужен);
* исходящий доступ к `github.com` и к прокси Go-модулей (`proxy.golang.org`).

При запуске от root `gameapctl` устанавливает их сам; в пользовательском режиме (`--scope user`)
они должны быть установлены заранее.

## Требования к выделенному серверу

Для автоматической установки демона нужны:

* права root (Linux) или администратора (Windows);
* утилиты `curl`, `tar` и `install` — для Linux-скрипта установки;
* исходящий доступ к `github.com` и `api.github.com` — оттуда скачиваются gameapctl и демон;
* исходящий доступ к панели по порту 31718.

Пакеты, необходимые для работы демона и игровых серверов — в том числе SteamCMD и менеджер
процессов — `gameapctl` установит сам. Подробнее —
[Выделенные серверы](/ru/gameap_configure/dedicated_servers.html).

### Curl

Если `curl` в системе нет, установите его:

```shell
# Debian, Ubuntu
apt install curl

# CentOS, RHEL, Fedora
yum install curl
```
